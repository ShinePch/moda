구분 다이어그램 설명
정적모델
(시스템구조)		 클래스 다이어그램 시스템의 클래스, 속성, 메서드 및 클래스 간의 관계를 보여줌
컴포넌트 다이어그램 시스템의 물리적 구성 요소와 그들 사이의 의존성을 보여줌
배치 다이어그램 시스템의 물리적 아키텍처를 나타냄
패키지 다이어그램 시스템의 패키지 구조와 그들 사이의 의존성을 보여줌
동적모델
(시스템행위)		 유스케이스 다이어그램 시스템과 사용자(액터) 간의 상호작용을 나타냄
순차(시퀀스) 다이어그램 객체 간의 상호작용을 시간 순서대로 보여줌
통신 다이어그램 객체 간의 상호작용을 구조적 관점에서 보여줌
활동 다이어그램 업무 프로세스나 알고리즘의 흐름을 나타냄
상태 다이어그램 객체의 상태 변화와 이벤트에 따른 전이를 보여줌

응집도 (Cohesion)
강도 기호 한글이름 영어이름 의미/주요기능
낮음 우 우연적 Coincidental 각 구성 요소들이 연관이 없음
논 논리적 Logical 유사한 성격, 특정 형태로 분류들이 한 모듈에서 처리
시 시간적 Temporal 특정 시간에 처리
절 절차적 Procedural 모듈 안 기능들이 순차적
통 통신적 Communication 동일한 입력과 출력을 사용하여 다른 기능을 수행
순 순차적 Sequential 출력값을 다른 활동이 사용
높음 기 기능적 Functional 모듈 내의 기능이 단일한 목적을 위해 수행
결합도 (Coupling)
강도 기호 한글이름 영어이름 의미/주요기능
높음 내 내용 Content 다른 모듈 변수나 기능을 또 다른 모듈에서 사용
공 공통 Common 전역변수
외 외부 External 외부로 선언한 변수를 다른 모듈에서 참조
제 제어 Control 값뿐만 아니라 제어 요소까지
스 스탬프 Stamp 배열, 오브젝트, 스트럭처까지 전달
낮음 자 자료 Data 모듈간의 자료(값)을 통해서만 모듈 상호 작용 발생
