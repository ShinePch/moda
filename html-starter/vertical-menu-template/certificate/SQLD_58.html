📊 기타 복기된 문제들
  • COUNT(*) 4보다 큰 값: 칼럼 {1,2,3,4}에서 > 4 조건 → 공집합
  • LEVEL >= 2 결과: 계층 쿼리 → 2개
  • 정규표현식: ^₩w*$로 해당안되는 것 → 대시(-) 있는 것
  • PIVOT 문제: PLACE별 JAN,FEB,MAR 칼럼 변환 → NULL값 없는 선지
  • ERD 실선 관계: 계약-사용자 관계 해석 → 사용자-계약 관계 선지
  • GRANT 권한: D→user1,2,3 후 user2 REVOKE → D, user1, user3
  • 정렬 NULL: 여러 정렬 조건에서 NULL 처리 → NULL을 최대로 정렬

  • 실무 중심: 실제 업무에서 자주 사용하는 SQL 함수와 구문

  • 복합 문제: 여러 개념을 조합한 문제 증가 (WITH + 서브쿼리 등)
