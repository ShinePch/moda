서브넷마스크 계산 문제
문제 1: FLSM 네트워크 분할 (2022년 3회)
문제: 192.168.1.0/24인 네트워크를 FLSM 4개로 분할하였다.
두번째 네트워크의 브로드캐스트 IP를 10진수로 변환한 값을 작성하시오.
풀이 과정
  1. 원래 네트워크: 192.168.1.0/24 (호스트 256개)
  2. 4개로 분할: 256 ÷ 4 = 64개씩
  3. 각 서브넷:
    • 1번: 192.168.1.0/26 (0~63)
    • 2번: 192.168.1.64/26 (64~127)
    • 3번: 192.168.1.128/26 (128~191)
    • 4번: 192.168.1.192/26 (192~255)
정답: 192.168.1.127
서브넷마스크 FLSM 중급
문제 2: 네트워크 주소 계산 (2022년 2회)
문제: IP 주소가 139.127.19.132이고 서브넷마스크 255.255.255.192일 때
(1) 괄호안에 들어갈 네트워크 주소: 139.127.19.( )
(2) 해당 네트워크 주소와 브로드캐스트 주소를 제외한 호스트 개수
풀이 과정
  1. 서브넷마스크 분석: 255.255.255.192 = /26
  2. 192를 2진수로: 11000000 (상위 2비트가 네트워크)
  3. IP 주소 132를 2진수로: 10000100
  4. 네트워크 부분: 10000000 = 128 (AND 연산)
  5. 호스트 비트: 6비트 = 2⁶ = 64개
  6. 실제 호스트: 64 - 2 = 62개
정답:
(1) 128
(2) 62

문제 3: CIDR 라우팅 계산 (2024년 1회)
문제: 네트워크에서 라우터을 통한 할당 가능한 2번, 4번, 5번의 IP를 작성하시오.

주어진 정보:
1) 192.168.35.3/24
3) 129.200.10.16/22
6) 192.168.36.24/24
풀이 과정
  1. 각 네트워크 분석:
    • 192.168.35.3/24 → 네트워크: 192.168.35.0
    • 129.200.10.16/22 → 네트워크: 129.200.8.0
    • 192.168.36.24/24 → 네트워크: 192.168.36.0
  2. 라우팅 테이블 매칭:
    • 2번: 35 네트워크 범위 → 192.168.35.72
    • 4번: 129.200.8.0/22 범위 → 129.200.8.249
    • 5번: 36 네트워크 범위 → 192.168.36.249
정답:
2) 192.168.35.72
4) 129.200.8.249
5) 192.168.36.249
