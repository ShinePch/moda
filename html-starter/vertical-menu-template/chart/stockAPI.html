위의 버튼을 클릭하여 스캔을 시작하세요

분석 기준
  • 데이터: Yahoo Finance (무료, API 키 불필요)
  • 타임프레임: 분봉 직접 입력 또는 일봉/주봉/월봉 선택
  • MA 기간: 직접 입력 (예: 10, 56, 644)
  • 괴리율 최솟값~최댓값: 방향 구분 가능 (예: 0~+3% → MA 위 접근만 / -3~0% → MA 아래 접근만)
  • 괴리율 양수: 현재가가 MA 위 / 음수: 현재가가 MA 아래

주의사항:

자동매매 기능은 현재 개발 중입니다. 실제 거래 시 충분한 테스트 후 사용하세요.

  • 🔄 자동 매수/매도 전략
  • 📊 실시간 가격 모니터링
  • ⚠️ 리스크 관리 도구
  • 📱 알림 시스템

1. Bybit 계정 준비
  • Bybit 공식 사이트에서 계정 생성
  • 본인인증 완료 (KYC)
  • 2단계 인증(2FA) 설정 필수
2. API 키 발급
  • 계정 설정 → API Management 이동
  • "Create New Key" 클릭
  • 권한 설정: Read Only만 체크 (보안상 권장)
  • IP 화이트리스트 설정 (선택사항)
3. 보안 주의사항
  • API 키를 절대 다른 사람과 공유하지 마세요
  • 처음에는 Read-Only 권한만 사용하세요
  • 정기적으로 API 키를 갱신하세요
  • 의심스러운 활동 발견 시 즉시 키를 비활성화하세요
