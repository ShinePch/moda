📊 스캔 결과
🎯 검색 결과가 여기에 표시됩니다

위의 버튼을 클릭하여 스캔을 시작하세요

사용 방법:
  1. API 키 설정: Bybit 계정에서 Read-Only API 키 발급
  2. 연결 테스트: API 키가 정상 작동하는지 확인
  3. 빠른 스캔: 인기 코인 50개 대상으로 빠른 분석
  4. 전체 스캔: MA448/644 기준으로 전체 분석

주의사항:

자동매매 기능은 현재 개발 중입니다. 실제 거래 시 충분한 테스트 후 사용하세요.

  • 🔄 자동 매수/매도 전략
  • 📊 실시간 가격 모니터링
  • ⚠️ 리스크 관리 도구
  • 📱 알림 시스템

1. Bybit 계정 준비
  • Bybit 공식 사이트에서 계정 생성
  • 본인인증 완료 (KYC)
  • 2단계 인증(2FA) 설정 필수
2. API 키 발급
  • 계정 설정 → API Management 이동
  • "Create New Key" 클릭
  • 권한 설정: Read Only만 체크 (보안상 권장)
  • IP 화이트리스트 설정 (선택사항)
3. 보안 주의사항
  • API 키를 절대 다른 사람과 공유하지 마세요
  • 처음에는 Read-Only 권한만 사용하세요
  • 정기적으로 API 키를 갱신하세요
  • 의심스러운 활동 발견 시 즉시 키를 비활성화하세요

주요 API 엔드포인트
용도 엔드포인트 설명
서버 시간 /v5/market/time Bybit 서버의 현재 시간 조회
티커 정보 /v5/market/tickers 코인별 가격, 거래량 등 기본 정보
K라인 데이터 /v5/market/kline 차트 데이터 (OHLCV)
계좌 정보 /v5/account/wallet-balance 보유 자산 조회
