데이터 소스
  • Yahoo Finance 일봉 기준 월별 거래량 합산 (API 키 불필요, 무료)
핵심 조건
  • 거래량 조건: 이번달 제외, 최근 N일 범위 내에서 저번달(1달 전) 거래량 합계가 가장 높은 종목만 통과
  • 저번달 양봉 조건 (선택): 저번달 시가 < 저번달 종가 → 저번달에 상승 마감한 종목만
  • 월봉 MA 조건 (선택): 현재 종가가 지정한 MA선 기준 괴리율 범위 안에 있는 종목
  • 월봉 MA120 조건 (선택): MA120과 MA10의 위치 관계 + 괴리율 범위 설정 가능
  • 월봉 MA60 > MA10 조건 (선택): MA60이 MA10 위에 있는 종목만 (중장기 상승 추세 확인용)
사용 목적
  • 저번달에 거래량이 급등(폭발)한 종목을 찾아냄
  • 급등 후 이번달 월봉 MA10선에 눌림 접근 중인 종목 포착 가능
  • MA60 > MA10 조건 추가 시 중장기 우상향 추세인 종목만 필터링
기본값 / 주의사항
  • 조회 기간 기본값: 180일 (약 6개월)
  • 괴리율 기본값: -3% ~ +3%
  • 거래량 최고 달은 무조건 저번달(1달 전) 고정 → 더 유연한 설정은 v2 사용

v1과의 차이점
  • v1은 거래량 최고 달이 저번달(1달 전) 고정
  • v2는 거래량 최고 달 범위를 직접 설정 가능 (예: 1~3달 전)
  • 급등 후 도지 캔들 or 횡보로 눌림이 1달 이상 이어지는 경우도 포착 가능
핵심 조건
  • 거래량 조건: 최근 N개월 범위 내에서 거래량 최고 달이 지정한 X~Y달 전 사이에 있는 종목
  • 예시 (1~3달 전): 저번달 / 저저번달 / 3달 전 중 하나가 거래량 최고이면 통과
  • 거래량 최고 달 양봉 조건 (선택): 거래량 최고였던 그 달의 시가 < 종가 → 해당 달이 상승 마감
  • 월봉 MA 조건 (선택): 현재 종가가 지정 MA선 괴리율 범위 안에 있는 종목
  • 월봉 MA120 조건 (선택): MA120과 MA10의 위치 관계 + 괴리율 범위 설정 가능
  • 월봉 MA60 > MA10 조건 (선택): MA60이 MA10 위에 있는 종목만
사용 시나리오
  • 시나리오 1: N달 전 거래량 폭발 + 급등 → 이후 도지/횡보 눌림 → 이번달 MA10 접근 중
  • 시나리오 2: 거래량 최고 달 범위를 1~1로 설정하면 v1과 동일하게 동작
  • 추천 설정: 범위 1~3달 전, MA 조건 괴리율 0~+5% (MA10 위에서 접근 중인 종목)
주의사항
  • MA60, MA120 계산은 월봉 15년치 데이터를 별도 요청 → 종목당 API 호출 2회 (속도 다소 느림)
  • 조회 기간(개월)은 거래량 집계 범위이므로 최소 maxAgo + 1 이상으로 설정 권장
  • 거래량 최고 달 범위: 최솟값 ≤ 최댓값이어야 함

주의사항:

자동매매 기능은 현재 개발 중입니다. 실제 거래 시 충분한 테스트 후 사용하세요.

  • 📱 알림 시스템

1. Bybit 계정 준비
  • Bybit 공식 사이트에서 계정 생성
  • 본인인증 완료 (KYC)
  • 2단계 인증(2FA) 설정 필수
2. API 키 발급
  • 계정 설정 → API Management 이동
  • "Create New Key" 클릭
  • 권한 설정: Read Only만 체크 (보안상 권장)
  • IP 화이트리스트 설정 (선택사항)
3. 보안 주의사항
  • API 키를 절대 다른 사람과 공유하지 마세요
  • 처음에는 Read-Only 권한만 사용하세요
  • 정기적으로 API 키를 갱신하세요
  • 의심스러운 활동 발견 시 즉시 키를 비활성화하세요
